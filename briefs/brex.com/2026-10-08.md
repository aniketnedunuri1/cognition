## Verdict

**Warm** *(assessment)* — Brex is partway through a Micronaut 4 migration across 500+ Kotlin microservices and says the remainder still needs de-risking; its own write-up names test-suite gaps that let agent PRs through. Both map to Devin use cases with public fintech proof (Itaú, Nubank, Ramp). But self-hosted Cursor agents already run this work, an engineering JD asks for daily Claude Code or Cursor use, and Brex built its own platform for delegating engineering work to agents, so this is a displace-or-expand play: Warm, not Act now. [1][2][3][4]

Watch for: How much of the Micronaut 4 migration remains and whether the GraphQL federation upgrade is next. Signs platform wants to stop maintaining its self-hosted agent harness and in-house delegation platform. Capital One standardizing engineering tooling or procurement. A signed Cursor or Claude Code enterprise deal would move this to Not now.
