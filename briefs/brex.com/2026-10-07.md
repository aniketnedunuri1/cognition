# Brex — account brief
*2026-10-07 · brex.com*

## Verdict

**Warm** *(assessment)* — Brex is partway through a Micronaut 4 migration across 500+ Kotlin microservices and says the remainder still needs de-risking. Its own write-up names test-suite gaps the agents exposed. That maps to Code migration & modernization, with public fintech proof from Nubank and Itaú. But Brex runs this exact workload on self-hosted Cursor agents, widens Claude Code and Cursor access internally, and has built its own platform for delegating engineering work to agents. So this is a displace-or-expand play. It's Warm rather than Act now because a direct competitor is in production. [1][2][3][4]

Watch for: How much of the Micronaut 4 migration is left, and whether the GraphQL federation upgrade is next. Signs the platform team wants to stop maintaining its self-hosted agent harness and in-house delegation platform. Capital One standardizing engineering tooling or procurement after the acquisition. Cursor renewal timing. A signed Claude Code or Cursor enterprise deal, which would move this to Not now.
